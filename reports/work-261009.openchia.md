## Headline

Upstream #66 (Nicholas, 10-08) made `/build` a **refiner-driven construction campaign**: a Designer plus Materialization/Code/Measure/Verify specialists, with no planner/emitter pre-pass. On our **Argo-only** route that path broke repeatedly, and each fix uncovered the next failure. The sequence, all merged:

1. **No coding adapter for `chat_completions`.** Fixed with an Argo coding adapter (#67).
2. **Step budget too small**, and an exhausted budget killed the Run. Fixed in #71.
3. **The coder's shell was unconfined.** It now runs in a per-turn container (#74).
4. **Argo stream drops killed the coder turn.** Fixed with retries plus smaller context (#75).
5. **The same drops killed the shared model transport.** Fixed by replacing dropped attempts (ADR 0008 amendment, #76).
6. **The VPN dropped mid-request,** causing a multi-hour silent stall. Fixed with keepalive, a waiting heartbeat, an unreachable-provider end, and refiner calls visible in `/build status` (#78; closes #77).
7. **The coding loop exhausted the user's monthly Argo quota.** Three turns, 5.8–7.8M input tokens each, with no file written. Fixed with guardrails (#79), and missing modules now go through the Builder emitter in **one call** (#81).

**No Episode build completed on the new path.** The Argo quota is exhausted, so #81 is not yet validated end to end.
