**Findings that feed the plan:**
- **Cost:** yield has no cost term, and failures cost nothing.
- **Allocation:** child allowances, chosen by the model, ended at least 38 of V9's Episodes.
- **Root:** the root never stopped on yield.
- **Context size:** request size grew about 5× over the run (median 70K → 388K characters; a late root proposal was about 50× an early query), so the cost unit should be tokens.
- **Refusals:** they track operation and content, not request size.
- **Tool choice:** the root asked a tool for metrics it does not own.
- **Stale results:** stale calculations are never recomputed.
